Python Programming Tasks
This repository contains four Python programming tasks completed as part of my internship. These projects helped me practice Python fundamentals, problem-solving, automation, and basic programming concepts.
Tasks
1. Hangman Game
A simple word-guessing game where the player tries to guess a randomly selected word within a limited number of attempts.
2. Stock Portfolio Tracker
A program that calculates the total value of a stock portfolio based on stock prices and the quantities entered by the user.
3. Task Automation
A Python script that automatically identifies JPG files in a folder and moves them to a specified destination folder.
4. Basic Chatbot
A simple rule-based chatbot that responds to basic messages such as greetings and goodbye.
